Mô Phỏng Giao Thức Mạng & Bảo Mật

Khám phá cách QuizAI hoạt động ở tầng mạng: Cơ chế bắt tay 3 bước TCP, cấu trúc gói tin HTTP RESTful, xác thực JWT và mã hóa bảo mật HTTPS.

1. Cơ Chế Bắt Tay 3 Bước (TCP 3-Way Handshake)

Trước khi gửi bất kỳ câu trả lời nào, Client và Server phải thiết lập kết nối TCP tin cậy:

BƯỚC 1: CLIENT → SERVER (SYN)
Client (Port ngẫu nhiên 54210) gửi gói tin SYN với seq = 1000 để yêu cầu kết nối.
BƯỚC 2: SERVER → CLIENT (SYN-ACK)
Server (Port 5000) chấp nhận: gửi SYN với seq = 5000 và ACK = 1001 (xác nhận gói SYN).
BƯỚC 3: CLIENT → SERVER (ACK) [ESTABLISHED]
Client gửi ACK = 5001. Kết nối chính thức ESTABLISHED. Bắt đầu truyền HTTP Request.

2. Soi Gói Tin HTTP RESTful (Packet Inspector)

Bản tin HTTP Request được gửi qua mạng:

POST /api/submissions/submit HTTP/1.1
Host: localhost:5000
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6...
Content-Type: application/json

{
  "submissionId": 14,
  "answers": [
    { "questionId": 101, "selectedOptionId": 402 },
    { "questionId": 102, "selectedOptionId": 405 }
  ]
}

3. Giải Mã Cấu Trúc Token JWT (Stateless Token)

Token gồm 3 khối phân tách bởi dấu chấm, mang chữ ký số HMAC-SHA256:

HEADER: Thuật toán & Loại Token { "alg": "HS256", "typ": "JWT" }
PAYLOAD: Claims Người Dùng { "nameid": "1", "name": "admin", "role": "TEACHER", "exp": 1792072686 }
SIGNATURE: Chữ Ký Số Bí Mật HMACSHA256(base64UrlEncode(header) + "." + base64UrlEncode(payload), SecretKey)

4. Cơ Chế Bảo Mật HTTPS (Chống Wireshark Sniffing)

So sánh giữa truyền HTTP trơn và HTTPS có mã hóa TLS:

⚠️ HTTP Thường
Kẻ tấn công dùng Wireshark đọc được rõ:
"username": "student1"
"password": "123456"
🔒 HTTPS (TLS 1.3)
Mã hóa AES-256 đối xứng, chỉ thấy chuỗi byte ngẫu nhiên:
a7f29b8c04e1d...
★ Điểm mạnh: Server và Client dùng mã hóa bất đối xứng để trao đổi Secret Key, sau đó chuyển sang mã hóa đối xứng AES để tối ưu băng thông mạng.
